## 1. 计划总览

### 1.1 为什么要分阶段

项目范围横跨界面、状态、领域逻辑、数据、题库、书城、判题、PWA。一次性全做，任何一个环节卡住都会导致整体无法运行，也无法定位问题。分阶段的唯一目的：**让每个阶段结束时都有一个能在浏览器里打开、能亲手点、能看到结果的东西**。

阶段划分与 PRD 的版本规划一一对应：

| 阶段 | 名称 | 结束时能做什么 | 对应 PRD |
|---|---|---|---|
| 阶段 0 | 环境与骨架 | 打开网页看到空壳界面，能构建、能部署 | 准备 |
| 阶段 1 | MVP 闭环 | 走完"引导→做题→看双答案→得金币→买内容→刷新不丢" | 第一期 |
| 阶段 2 | 质量与自动化 | 实操题自动判题、题库自动生产、成就打卡完整 | 第二期 |
| 阶段 3 | 规模化 | 第二语言、多语言判题评估、后端可行性评审 | 第三期 |

### 1.2 硬性执行原则

这五条来自协作约定，先写在最前面，后续所有任务都遵守：

1. **每步一个可验证成果**：一个任务完成后，必须能用一句话说清"现在能看到什么"，且能实际打开验证。
2. **单一最小版本**：一次只交付一个能运行的最小改动，不把多个功能揉在一次提交里。
3. **不可逆操作先确认**：删除文件、覆盖代码、推送远端、公开仓库、清除用户数据，执行前明确说明并征得同意。
4. **改动可追溯**：每次交付说明"改了哪些文件、为什么、怎么验证"；代码与文档同步更新。
5. **技术选型需批准**：文档未覆盖的新库、新方案，先给理由和取舍再采用。

| # | 卡点 | 影响 | 处理方式 |

## 7. GitHub 推送流程（常态化）

由于沙箱直连 `github.com:443` 超时，`git push` 不可用，推送统一走 GitHub API 通道。流程已固化为脚本 `scripts/push-via-api.mjs`，每次推送照此执行：

1. **确认凭证**：token 从环境变量 `GH_TOKEN` 读取，不写入文件、不打印（token 曾明文暴露，用后建议维护者轮换）；
2. **本地提交**：先在本地正常 `git add` / `git commit`，测试与构建通过后再推；
3. **执行推送**：`GH_TOKEN=xxxx node scripts/push-via-api.mjs`，脚本自动完成：
   - 从 `git cat-file` 读取已提交的文件内容（**不是重读工作区**，保证推的就是提交的版本）；
   - 逐提交重建 tree、commit 并更新远端 ref；
   - 校验远端 tree 与本地 tree 一致，不一致则中止，不用 force 覆盖；
   - 用枚举法在本地重建同 SHA 的 commit 对象，使本地与远端对齐。
4. **核验**：确认本地与远端 HEAD、tree SHA 一致（`git status -sb` 显示 `## main...origin/main` 无领先/落后）。

> **历史教训**：早期用临时脚本重读工作区文件，曾把编辑前的旧版文档推上远端，且 API 会规范化提交时间戳导致本地 SHA 反复对不齐，最后靠 `force` 覆盖修正——有改写历史风险。固化为脚本后此类问题消除。不再使用 force 覆盖。

## 10. 全端适配与视觉气质决策（v1.1 并入）

本章记录全端适配与视觉气质的五项定稿决策，作为阶段 0.5 及后续界面任务的强制约束。决策依据来自对 Material Design 3 布局规范、主流 React 组件库、游戏化学习 UI 模式的调研比对；调研底稿不随仓库分发，结论在本章自包含。

### 10.1 五项决策与执行口径

| # | 决策项 | 定稿 | 执行口径 | 落地任务 |
| --- | --- | --- | --- | --- |
| D1 | 组件库路线 | 布局与视觉骨架自研；复杂交互按需借 Radix 原语；不引入全家桶 | 页面布局、卡片、玻璃效果一律自研；Dialog/DropdownMenu/Toast 等有键盘/读屏要求的交互用 Radix，视觉仍套玻璃令牌。禁止引入 MUI/Ant Design/TDesign/Vant 等成套库 | T0.8、T0.11、T1.24 |
| D2 | 底部标签栏 | 4 项：首页/学习/书城/我的；设置收进「我的」 | 手机端底部固定 4 项，留出第 5 项扩展位；主题切换从顶部导航移除，并入设置页，顶栏只留必要操作 | T0.8 |
| D3 | 游戏化强度 | 克制点缀，不照搬多邻国高饱和 | 保留青碧主色；金币/等级/连击用小徽标，动效 150–300ms；不用大面积高饱和、满屏彩带、3D 立体按钮 | T0.10、T1.14 |

### 10.2 三档断点与导航映射

| 档位 | 宽度 | 导航形态 | 内容布局 |
| --- | --- | --- | --- |
| 手机 Compact | < 640px | 底部标签栏 4 项 + 顶部应用栏 | 单栏，左右 16px 边距 |
